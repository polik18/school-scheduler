## 可存取性改善

- 使用說明開啟後將焦點移入對話框，Tab／Shift+Tab 不會跑到背景內容；Esc 關閉後焦點回到「使用說明」。
- 人工調課格加入可辨識名稱、鍵盤焦點與 Enter／Space 操作。
- 背景排課的視覺數字仍即時更新，但螢幕閱讀器狀態改為低頻訊息，避免每 250ms 重複播報。
- `prefers-reduced-motion: reduce` 下停止課表格動畫。
- 核心文字與狀態配色以 WCAG 4.5:1 作為程式門禁。
- 修正手機工作區因 680px 課表造成的頁面水平溢位；課表改在自己的容器內橫向捲動。

## 響應式與列印

- 360px：工作區本身不水平溢位；寬課表留在可橫向捲動容器。
- 768px、1440px：單一對象課表、搜尋、摘要與科目圖例維持清楚層級。
- 列印模式只保留目前課表，隱藏操作、其他面板、頁首與頁尾。
- 視覺門禁的 PNG 產物寫入 `test-results/visual/`，不納入版本控制。

## CI 與部署

- Test workflow 執行單元、標準範本、72 班、瀏覽器 E2E 與視覺門禁。
- Pages build 在部署前也執行相同核心門禁與視覺稽核。
- 正式站部署後再執行 `npm run test:e2e:live`。

## 已知邊界

- 課表在 360px 必須於表格容器內橫向捲動，這是維持五日欄位可讀性的設計選擇。
- 課程分散度目前只衡量同班同科集中於同一天，不代表完整教學品質或全域最佳解。
- 60 班資料依課綱節數建立，但師資、場地及彈性課程名稱是合成假設，正式使用前仍須換成本校核定資料。
- 自動化檢查不能取代實際使用輔助科技的人工驗證；未來若進行正式無障礙標章申請，仍需 NVDA／VoiceOver 與人工色彩、縮放檢測。
