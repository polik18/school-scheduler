# Excel 匯入說明

## 五分鐘快速上手

1. 從首頁下載唯一的「標準範本」。
2. 先不修改直接匯入，確認 60 班範例能通過驗證與排課。
3. 從各工作表第 3 列起，分批替換成貴校資料。
4. 保留工作表名稱及第 2 列中文欄位。
5. 匯入後先修正紅色錯誤，再開始排課。

## 工作表

- 班級：班級代碼、年級、班級名稱、學生數、導師代碼、備註
- 教師：教師代碼、姓名、主要領域、每日最多節數、最多連續節數、身分備註
- 課程：班級代碼、科目、教師代碼、每週節數、教室類型、是否連堂
- 教師可排時段：教師代碼、星期、節次、是否可排、原因
- 教室：教室代碼、教室類型、容量
- 固定活動：活動名稱、星期、節次、班級代碼、教師代碼
- 行政職務：處室／單位、職稱、教師代碼、姓名、備註

星期填「星期一」至「星期六」，是非欄位填「是／否」。班級、教師和教室代碼在不同工作表間必須完全一致。舊版英文工作表及欄位仍可匯入。

## 常見問題

- **教師／班級不存在**：課程表使用了主資料中沒有的代碼，請統一代碼。
- **找不到專科教室**：新增與課程要求相同類型的教室，或修正課程教室類型。
- **限制過緊**：逐步放寬不可排時段、每日節數、固定活動或增加專科教室。
- **排課逾時**：系統會保留目前最佳的部分課表；可查看未排入課程後調整限制。

完整互動說明可從網站頁首「使用說明」開啟。
