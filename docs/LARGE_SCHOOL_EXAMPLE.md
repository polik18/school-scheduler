# 大型學校排課範例

`public/examples/large-school-schedule-demo.xlsx` 由匿名化的 115 學年度教職員配置資料整理，用來讓使用者直接體驗大型資料匯入、驗證、排課與匯出。

逐筆中文任教文字的展開結果記錄在 `public/examples/large-school-example-report.json`，可用來對照原文、科目與展開後班級。

## 資料規模

- 54 個國小班級（一至六年級，每年級 9 班）
- 54 位匿名級任教師
- 70 筆匿名科任／支援人員資料
- 依原簿的科目與任教班級文字展開成結構化 `Courses`
- 40 筆行政與支援職務

## 重要界線

原始人員簿沒有提供實際每週節數、學生人數、教室與不可排時段。因此範例檔明確使用以下演示假設：

- 專科配置每班每週 1 節。
- 級任國語與數學各每週 3 節。
- 每班 30 人，普通教室容量 35 人。
- 週一第 1 節設為全校固定活動，另放入兩筆教師不可排時段作為範例。
- 來源中有科任每週對應 36 個班級，因此科任的演示上限設為每日 8 節；這不代表實際授課時數。

這些數值只為體驗系統，**不是該校實際課程計畫**。正式排課前必須依學校課程計畫修正。

## 重建範例

```bash
npm run build:demo
```

轉換程式在 `scripts/build-large-school-example.mjs`，預設讀取 `public/examples/staffing-result-demo.xlsx`。
