# 60 班標準範本

`public/school-scheduler-template.xlsx` 是網站唯一對外的標準範本。使用者可不修改直接匯入試跑，也可刪除第 3 列起的範例後填入本校資料。

## 資料規模

- 60 個國小班級（一至六年級，每年級 10 班）
- 136 筆中性命名的級任、科任與支援人員
- 678 筆課程列，展開後 924 節
- 40 筆行政與支援職務
- 教師不可排、固定活動、連堂與專科教室範例

## 填寫規則

- 每張表第 1 列是中文說明。
- 第 2 列是系統識別用的英文欄位，請勿刪除或改名。
- 第 3 列起的範例可全部刪除。
- 正式排課前必須依本校課程計畫修改節數、教室、固定活動與教師可用時段。

## 隱私

公開範本只使用「級任教師001」、「科任教師001」等中性名稱，不含原始或遮蔽後姓名。

## 重建與驗收

```bash
npm run build:template
npm run test:template
npm run test:capacity
```

- 產生器：`scripts/build-standard-template.mjs`
- 標準範本 60 班門禁：30 秒內、924 節、0 pending、0 硬衝突
- 72 班壓力門禁：即使觸發超時，也必須保留無硬衝突的部分結果
